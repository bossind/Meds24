# Meds24 Telegram Bot & Admin Mini App Guide

## Telegram Bot Setup
1. Talk to `@BotFather` on Telegram to create a new bot and obtain your `TELEGRAM_BOT_TOKEN`.
2. Set the WebApp URL in `@BotFather` menu or configure `TELEGRAM_WEBAPP_URL` in `.env`.
3. The bot supports commands like `/start` and provides instant buttons to open the Admin Mini App.

## Admin Mini App Features
- Real-time store order monitoring & revenue analytics.
- Order status updates (Pending -> Confirmed -> Out for Delivery -> Delivered -> Cancelled).
- Fully responsive mobile UI optimized for Telegram WebApp.
